# 学习观测与选题策略

目标：让不同客观作答证据影响选题，同时保留模型假设与原始事实。本文中的数字是可配置默认值，不是已经验证的最优学习规律。

## 1. 三个不同问题

| 组成 | 回答的问题 |
| --- | --- |
| 表现证据 | 在这些题目与观测条件下，有多少证据说明可以完成该任务？ |
| 记忆模型 / FSRS | 按当前模型，间隔复习何时更值得安排？ |
| 混淆统计 | 在实际提供过的选项中，哪些干扰项经常被错选？ |

SelectionPolicy 结合三者选择目标词、task_family 与合格题目形式。题库只是候选边界；unit 为单人的 `(sense_id, task_family)`，不是题目实例，也不是题库。

## 2. 事实属性与观测解释

观测条件并非互斥枚举，应分别记录或从事实派生：

```text
source: practice | exam
purpose: normal | correction | early_review
response_history: single_response | revised | telemetry_incomplete | omitted
exposure: same_form_seen / related_lexeme_seen / feedback_seen
timing: same_unit_interval / time_since_related_exposure / same_session
quality: valid | disputed | invalidated
```

一次考试首次选择可以同时是提前复习，并受到另一题的提示。上述条件必须能同时表达。

“无已知近期提示的观测”是系统内可检查的标签，不能证明心理学意义上的独立性，也不能排除系统外查词。first_selected 只表示首次观察到的选择，不能自动等于首次真实提取。

ObservationPolicy 读取事件、曝光历史、题目版本及事件修订，派生：计入哪些统计组、是否生成 FSRS review、其时间/评级、为什么排除、是否存在未被模型表达的暴露。policy version 与投影一起保存，不把 fsrs_eligible 永久写死在原始事件中。

## 3. 首版建议观测策略

| 观测 | 表现证据 | FSRS 建议 |
| --- | --- | --- |
| 合法普通训练提交 | 正常作答分组；额外按已知提示/形式分层 | 正确 Good、错误 Again，一次 |
| 反馈后纠错 | correction 分组 | 每次有效提交使用真实时间和同日分支更新一次；不额外奖励 |
| 提前复习 | early_review 分组 | 一次，实际间隔 |
| 考试已交卷、可靠完整时间线、一次选择且未改答 | exam single_response 分组 | 一次；时间引用该选择被服务器接收的时刻 |
| 考试发生改答或时间线不完整 | 保存首次、最终及变化过程 | 首版暂不生成 review，记录排除原因和未建模暴露 |
| 未提交训练、考试未答 | abandonment/omitted 独立统计 | 不写 Again |
| 已确认题目无效 | 保留原事实，附无效处置 | 按修订策略重建，不能静默重判 |

考试改答仍按最终答案评分。改答题排除 FSRS 是保守工程策略，不是“首次/最终答案没有价值”的结论；在后续实验中可以比较“最终答案单次更新”等备选策略。

“一次”以有效业务提交为单位，不以整轮纠错为单位。例如普通题答错、第一次纠错答错、第二次纠错答对，产生三个不同的作答事件及三个 review；每个事件重发不增加 review，队列完成也不再生成 review。纠错次数上限不改变这一事件语义。

服务端无法判断心理上的误触。已经接受的合法训练错误按观察到的错误映射 Again，报告不将其表述为已证明的真实记忆失败；重复请求、非法载荷和明确失效事件按幂等/修订规则处理。不能因点击速度快就自动删除不利记录。

被排除的作答仍造成暴露：保留 exposure gap 标记，不把相关跨暴露区间当作干净的延迟验证样本，也不直接用于参数优化。当前 due_at 不因改答成功被推迟。仅有暴露不能把 last_review_at 改到新时间而保留旧 S/D，这会虚构一次模型更新。

这些 unit 的 FSRS 预测仍是近似；首版没有声称解决所有未建模暴露的影响。下次有效 review 使用真实历史并保留模型偏离标记。后续变更策略须回放全部事实，而不是删掉不利记录。

## 4. FSRS 适配

推荐 FSRS-6 作为首版时间调度基线；Good/Again 二值映射不要求用户自评。Anki 支持二按钮使用方式，但对不同四选一形式的适用性仍需验证。[S01](06-sources.md)、[S02](06-sources.md)

FSRS 的 S 是天数；R 随时间变化；D 是模型中的记忆难度量。它们不直接等于题目难度、能力百分数或观察到的四选一正确率。多个不同形式合并为同一 sense/task unit，是明确的模型近似。

适配器输入包含不可变 review identity、实际时间、rating、旧状态、固定参数和算法实现版本。输出保存新状态与处理摘要。相同业务事实只生成一个符合策略的 review，纠错队列毕业不是额外 review。

默认不根据响应时间映射 Hard/Easy。RT 先作为分任务、形式和中断条件下的证据；“一秒熟练、五秒普通”不作为首版规则。normalized_rt_estimate 暂不要求实现，无有效样本时用 null 而不是 0。

首版先用固定参数，不用少量个人日志训练个人权重。desired_retention 是内部调度参数，建议以 0.90 为可回放起点；它不是对用户承诺九成真实掌握。[S01](06-sources.md)

## 5. 表现与混淆怎样实际影响选题

表现投影至少保留：有效样本数、正确数、正常/纠错/改答分组、最近普通观测、跨日期与题目形式覆盖。对外直接展示条件和数量；不把描述性正确率包装成完整能力模型。

首版选题的弱项规则建议保持离散、可解释：

- 无有效普通/考试单次选择观测的 task 标为未测，保留探索机会。
- 最近一次有效正常观测答错的 task 标为待巩固；反馈后纠错答对只结束本轮队列，不自动清除延迟观察需求。
- 若多个 task 都需要观察，优先证据较少或距有效观察更久者；不要用不同题型原始耗时直接排序。
- 报告样本少时使用“证据有限”；多次成功也只报告观察到的稳定表现，不承诺所有形式都掌握。

混淆投影记录每个干扰身份的 eligible_offered_count、wrong_selected_count 和最近时间，按正常/纠错分开。一次出现同一选项不重复计算分母。

分母具体定义为“有效作答实例中随题提供的该干扰项”，不宣称用户实际注视过它：

- 正常训练有效提交、已交卷且未改答的可靠考试观测，每个实例/干扰身份最多计一次；仅发题、退出、未答不计入主分母。
- 纠错的新实例可以各计一次，但仅进入 correction 分组，不能并入普通混淆率。
- 改答考试单独保留首次/最终错选计数和同一实例机会数；时间线不完整进入 uncertain 分组，不用于主混淆排序。
- 争议题暂不计入主统计；题目确认无效后通过修订回放移除对应分子/分母，原始作答和暴露仍保留。

同一目标词下选择题目形式时，可优先包含曾在至少 2 次普通观测中被错选的干扰项，并展示/保留其机会数。这个最小次数是初始规则，不是统计显著性。不能只按累计错选次数认定混淆强弱；一次错误也不扣减干扰词的学习状态。

题目正确率同时受个人状态、练习阶段、重复暴露和选题策略影响，不能直接当作 item difficulty。保存 question_form/version 和 selection_reason，首版主要用于异常发现与分层分析，暂不拟合 IRT。

## 6. 选下一题的流程

1. 找当前题库内有已发布题目的目标词义，排除停用/无效版本。
2. 应用会话、实例、sibling 和纠错约束。
3. 满足间隔条件的纠错先进入候选，但受次数上限限制。
4. 普通题在到期复习和未测/新内容之间轮换，建议每 4 个普通位置为未测内容预留 1 个。
5. 到期组优先当前应复习且待巩固的 task，再按 due_at、证据覆盖和有来源的内容重要度决定。
6. 未测组优先有内容可测但证据缺失的 task；词频缺失用中性值，不把未知状态设成零后排除。
7. 为选中的 unit 选择合格题目形式，结合形式近期使用与混淆记录；固定选项顺序并保存实例。
8. 保存 policy version、所属候选组、关键排序原因和随机输入。

不存在到期/未测候选时，继续练习可采用显式标记的提前复习。不为完成某个每日目标强行追加题目。无合法候选时返回明确原因。

## 7. sibling 与纠错

sibling_key 建议取 lexeme_id，以覆盖同词不同词义/题型的提示风险。

普通题默认距同一 lexeme 上次目标题至少出现 5 个其他 lexeme 的普通目标题；重复出现同一个其他 lexeme 不增加独立计数。这是可执行的冷却规则，不保证消除所有语义提示。

小题库无法满足时，使用其他满足约束的候选；如果全部被冷却，结束本轮并说明候选受限，不静默缩短间隔或卡死接口。可以保留后台内容扩充请求。该降级行为在小题库测试后再决定是否增加显式继续操作。

纠错按触发事件单独管理，允许作为普通 sibling 规则的例外；默认隔 3 个其他目标单词后重测。优先同一 task_family 的不同 question_form，版本不同但正文相同不算实质换题。仅洗牌不是新形式。

若没有合格替代形式，本轮保留待复习标记并请求离线补充内容，不密集循环原形式。不同形式难度可能变化，纠错成功仍只作为反馈后的证据。

每 unit 每会话最多 2 次纠错重试。成功结束该轮纠错；两次仍错则转为待以后复习。刷新恢复原会话计数；退出不生成错误。重新开始会话仍保留近期暴露信息，不把重新进入当作独立跨期证据。

## 8. 校准与可替换边界

先验证事务、事件顺序与投影回放，再比较学习效果。按任务、形式、间隔、改答、反馈暴露和是否被自适应选中分层，报告样本数。

评估预测误差时明确预测对象：FSRS R 并未自动校准为选择题 P(correct)，因此不能仅把 R 与选择题对错作 Brier/log loss 比较后宣称词汇能力校准完成。可把这种比较作为“选择题调度预测的经验偏差”，并保留猜测与题目差异说明。

保留固定间隔对照、有限探索样本及跨日测试。个人少量历史不足以区分题目难度与学习者状态，不承诺首版优于成熟产品。HLR/BKT/IRT 留作未来模型研究，不阻塞工程闭环。
